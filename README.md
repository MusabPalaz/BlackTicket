# CLA signatures

This branch only holds `signatures/version1/cla.json`, written by the CLA
Assistant workflow (`.github/workflows/cla.yml` on `main`) when a contributor
signs [CLA.md](https://github.com/MusabPalaz/BlackTicket/blob/main/CLA.md) on a
pull request. Do not merge it into `main` and do not edit it by hand.
